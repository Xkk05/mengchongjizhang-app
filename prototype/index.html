随心宠记账 · 原型 Demo

v0.2 对齐 iOS 实拍

依据《萌宠养成记账 APP 完整产品需求文档》绘制，并参照 iOS 端团团记账实拍截图重构视觉体系。11 个屏幕，覆盖记账核心、萌宠养成、游戏化闭环、数据统计四大块。

客户端 Flutter 单代码库 状态管理 Riverpod 本地库 Drift 原生桥 小组件 / 语音 云端 同步 / AI 解析
本版相对 v0.1 的改动：主色由薄荷绿改为珊瑚红强调色 + 自然场景背景，更贴近实拍的治愈系观感；主页从工具式卡片列表改为「场景 + 宠物居中 + 左右悬浮入口」的游戏化布局；新增签到奖励、团团商店、背包三个页面，补齐「记账 → 得金币 → 兑换 → 签到」的养成闭环；底部导航精简为 明细 / ＋ / 我的 三档，主 CTA 改为悬浮红钮。
